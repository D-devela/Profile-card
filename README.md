

This project is part of a frontend challenge and focuses on:

Clean, semantic HTML
Responsive design (mobile-first)
Accessibility basics
A bit of JavaScript for live updates
profile Info – name, bio, and avatar
Live Time – shows current time in milliseconds
Social Links – open in new tabs
Hobbies & Dislikes – simple categorized lists
Responsive Layout
Mobile → stacked
Desktop → side-by-side



 Accessibility



Semantic HTML (article, section, nav, etc.)

Visible focus states
Proper alt text for images
aria-live for time updates



 Design
Mobile-first layout
Flexbox for responsiveness
Clean card UI with subtle hover effects
Simple color system with gradients
System fonts for better performance



Limitations

Data is hardcoded (no editing)
No storage or backend
Avatar depends on external image
Some edge cases on very small screens
